## Tips

- Fill **Before** and **Evidence** for every row first. Only then start deciding. This stops you "fixing" a control you never actually measured.
- If a control has an audit procedure in the benchmark, follow it. The audit steps *are* the evidence method.
- A Pass with no evidence is a guess.
