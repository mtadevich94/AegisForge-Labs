# DC01 — Domain Controller

| | |
|---|---|
| **OS** | Windows Server 2022 (evaluation ISO) |
| **Resources** | 4 GB RAM (2 GB works), 2 vCPU, 60 GB disk |
| **Network** | `GielinorNAT` |
| **Address** | `10.10.10.10/24`, gateway `10.10.10.1`, DNS `127.0.0.1` (itself) |
| **Role** | Active Directory domain controller and DNS for `gielinor.local` |
| **Built by** | Windows Lab series (Student / Systems Administration) |

## Build

Follow the Windows Labs domain setup guide in `labs/Systems Administration/Windows Labs/`. In short: install Server 2022, set the static address above, name the machine `DC01`, install AD DS, promote to a new forest `gielinor.local`.

## Ready when

- `hostname` returns `DC01`
- `Get-ADDomain` returns `gielinor.local`
- Other VMs can resolve `gielinor.local`

## Verify

```powershell
hostname; (Get-ADDomain).DNSRoot; Get-NetIPAddress -AddressFamily IPv4 | Where IPAddress -like 10.10.10.*
```

## Snapshots

`post-install-clean` (after OS install), `domain-joined-clean` (after the domain is built and WKS01 joined).

## Used by

Windows Administration, Tiered Admin, optionally Packet Watch. **Not needed** by the Gatehouse.

## Expiry

Evaluation licence lasts 180 days. Rebuild from snapshots when it lapses.
