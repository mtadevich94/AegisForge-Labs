# FW01 — OPNsense Firewall

| | |
|---|---|
| **OS** | OPNsense Community 26.x (FreeBSD) |
| **Resources** | 2 GB RAM (4 GB with Suricata IDS), 2 vCPU, 12 GB disk |
| **Adapters** | 1: WAN `GielinorNAT`; 2: `realm-garrison`; 3: `realm-market`; 4: `realm-citadel` |
| **Addresses** | WAN `10.10.10.5/24` static, gateway `10.10.10.1`; LAN-side `.1` in each realm (`10.20.10.1`, `10.20.20.1`, `10.20.30.1`) |
| **Built by** | Network Segmentation lab (The Gatehouse), Networking |

## Build

Follow **Segmentation Lab Environment Setup** in `labs/Networking/Network Segmentation Labs/`. Because `GielinorNAT` has DHCP disabled, the WAN address is **static**: `10.10.10.5/24`, gateway `10.10.10.1`.

## Ready when

- Console menu shows WAN `10.10.10.5` and the three realm addresses
- The web UI loads from ADM01 at `https://10.20.30.1`

## Verify

From the FW01 console shell (menu option 8): `ping -c1 10.10.10.1`
